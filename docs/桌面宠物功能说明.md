# 桌面宠物 · 功能说明

> 一个悬浮在电脑桌面上的小宠物，**换一张图片，就换一个宠物**。

---

## 快速上手

1. 双击项目目录下的 `启动宠物.bat`。
2. 宠物会出现在桌面上，白底图片会自动变透明，像真的"贴"在桌面一样。
3. 关闭窗口时程序不会退出，而是缩小到右下角系统托盘，继续常驻。

---

## 功能一览

### 1. 更换宠物（两种方式）

| 方式 | 操作 | 说明 |
|------|------|------|
| **拖入图片即换** | 把图片文件直接拖到宠物身上，松手 | 最快捷，支持任意本地图片 |
| **菜单按钮更换** | 鼠标移到宠物上 → 右上角出现 ☰ 按钮 → 点击 →「更换宠物」→ 选择图片 | 弹出系统文件选择器 |

更换后宠物立即生效，并会被记住，下次启动自动用上次的宠物。

**支持的图片格式**：PNG、JPG、GIF、WEBP。

### 2. 自动抠图

- 白底或浅色底的图片（比如常见的白色背景动漫图、表情包），换宠时会**自动去掉背景**，宠物不再带白色方块。
- 已经是透明背景的 PNG 会原样显示，不做处理。
- 复杂背景（如照片）暂不支持自动抠图，建议提前用透明 PNG。

### 3. 移动宠物

- 按住宠物（鼠标左键）拖动，可放到屏幕任意位置，松手即停。
- 位置会被记住，下次启动还原到原处。

### 4. 置顶 / 取消置顶

- 鼠标移到宠物上 → 点右上角 ☰ 按钮 →「置顶」：让宠物始终浮在所有窗口之上（默认开启）。
- 再点一次取消置顶，宠物会被其他窗口遮住。

### 5. 快速唤出（防找不到）

取消置顶后宠物容易被挡住，用以下任意一种方式快速唤回：

- 按键盘快捷键 **`Alt + P`**
- 单击右下角系统托盘里的宠物图标

唤出不会改变你的置顶设置，只是临时把宠物提到最前。

### 6. 系统托盘常驻

- 关闭宠物窗口 → 程序最小化到托盘，不占任务栏。
- 托盘图标右键菜单：呼出宠物 / 显示隐藏 / 更换宠物 / 置顶 / 退出。

### 7. 记忆功能

程序会记住：当前宠物图片、窗口位置、置顶状态，重启后自动还原。

### 8. 帧动画（会动的宠物）

把同一只宠物的多张连续动作图放进**同一个文件夹**，文件名按「名字_序号」命名，例如：

```
cat_0.png   ← 第 1 帧
cat_1.png   ← 第 2 帧
cat_2.png   ← 第 3 帧
```

然后通过**菜单按钮**「更换宠物」或直接拖入**其中任意一张**（比如 `cat_0.png`），宠物就会自动循环播放这组动画。

- 眨眼、走路、待机等动作都可以用这种方式做。
- 如果只放一张图，就是静态宠物，不受影响。
- GIF 动图直接拖入/选择即可播放，无需拆帧。
- 内置示例：`assets/frames_demo/demo_0.png`（三帧眨眼表情），可拖入体验。

### 9. 互动反馈

- **点击宠物**：鼠标左键点一下宠物，它会原地弹跳一下，同时**弹出对话气泡**，随机说一句日常问候（比如「中午好」「吃饭了吗」「今天也要加油哦」等）。
- **对话内容**：从预设短句里随机选一条，尽量不连续重复；气泡几秒后自动消失。
- **悬停宠物**：把鼠标移到宠物身上（不按），宠物会轻微放大上浮，移开恢复。
- 拖动宠物时不会误触发弹跳和对话，两者已区分开。

### 10. 菜单按钮

宠物的所有操作入口都收在右上角的小圆钮里：

- **出现方式**：鼠标移到宠物身上时，宠物右上角淡入一个 **☰ 菜单按钮**（紧贴宠物，不飘在远处）；鼠标移开就自动隐藏，不挡视线。
- **点击展开**：点击 ☰ 按钮展开菜单，里面有「更换宠物 / 添加待办 / 查看状态 / 置顶 / 退出」。
- **菜单位置**：菜单从宠物的**上方**弹出，**不会遮住宠物**，也不会引起桌宠闪烁。
- **收起方式**：再点一次按钮、点菜单以外的任意位置、或切走窗口，菜单自动收起。
- 说明：界面取消了旧版「右键弹菜单」的方式，也不再显示宠物下方的提示文字，看起来更干净。

### 11. 气泡提醒（待办/消息）

宠物会在**头顶弹出三段椭圆气泡**（两个小椭圆气泡托起一个大椭圆对话气泡）提醒你：

- **添加待办**：点菜单「📝 添加待办」→ 弹出输入框 → 填写待办内容 + 「几分钟后提醒」（留空则立即提醒）→ 点「确定」→ 到点后宠物头顶弹出「⏰ 待办提醒」气泡。
- **自动提醒**：饱食度或心情过低时，宠物也会主动弹气泡撒娇（比如「😿 好饿呀」「😔 好无聊」）。
- **关闭方式**：气泡显示几秒后自动消失，无需手动关闭。
- 说明：所有气泡（喂食/玩耍/单击对话/待办提醒）现在都用同一种三段椭圆气泡样式，视觉统一。

### 12. 喂食心情（养成玩法）

把宠物当小动物养，它会**饿、会无聊**：

- **查看状态**：点菜单「📊 查看状态」，宠物上方弹出状态面板，显示两条进度条——🍖 饱食度、😊 心情，以及「喂食」「玩耍」两个按钮。
- **关闭状态面板**：点面板右上角的「×」按钮，或点面板以外的任意位置，面板就会消失。
- **喂食**：点状态面板的「喂食」按钮 → 饱食度 +30、心情 +15，宠物头顶会**冒出两个由小到大的椭圆气泡，然后汇聚成一个巨大的椭圆对话气泡**（位于宠物头部左上方）显示「🍖 吃饱啦！」。
- **玩耍**：点状态面板的「玩耍」按钮 → 心情 +20、饱食度 -5，宠物开心地弹跳，同样冒出椭圆小气泡 + 巨大椭圆气泡显示「🎾 好开心！」。
- **自然衰减**：饱食度和心情会随**时间慢慢下降**（每分钟一点点），所以要记得定期喂食、陪它玩。
- **数值范围**：都在 0～100，喂食/玩耍后自动保存，下次打开还保留。

### 13. 打包分发

- 用 `打包.bat` 一键打包，产物在 `dist/` 目录：
  - **安装包**：`桌面宠物 Setup x.x.x.exe`（可自选安装目录，自动创建桌面/开始菜单快捷方式）
  - **绿色版**：`桌面宠物 x.x.x.exe`（免安装，双击即用）

## 常见问题

**Q：拖入图片没反应？**
A：确认拖入的是图片文件（PNG/JPG/GIF/WEBP），拖入时宠物周围会有一圈蓝色高亮提示。

**Q：宠物怎么退出？**
A：鼠标移到宠物上，点右上角 ☰ 按钮 →「退出」，或托盘图标右键 →「退出」。

**Q：菜单在哪？怎么找不到？**
A：把鼠标移到宠物身上，右上角会出现 ☰ 按钮，点它即可展开菜单；鼠标移开按钮会隐藏（这是正常现象，避免挡视线）。

**Q：白底图片抠得不干净、有白边？**
A：当前抠图针对纯白底效果最好；底色偏灰、有渐变或复杂背景的图建议使用透明 PNG。
