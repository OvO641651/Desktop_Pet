### 关键环境坑（重要！）
1. **ELECTRON_RUN_AS_NODE=1**：WorkBuddy agent 环境全局设置了这个变量，导致 electron.exe 被当作纯 Node 运行，`require('electron')` 返回字符串路径而非 API 对象。启动时必须 `env -u ELECTRON_RUN_AS_NODE`。bat 里也 `set ELECTRON_RUN_AS_NODE=` 清空兜底。
2. **GPU 进程崩溃**（exit_code=-1073741819，"GPU process isn't usable"）：加 `--disable-gpu` 启动参数解决；agent 沙箱内还需 `--no-sandbox --in-process-gpu`。启动宠物.bat 用 `--disable-gpu` 即可。
3. `app.disableHardwareAcceleration()` 在此环境不足以阻止 GPU 进程启动，必须用命令行 `--disable-gpu`。

### Bug 修复记录
1. **拖不动**：CSS `-webkit-app-region: drag` 与右键菜单冲突、图片设 no-drag 占满窗口导致无法拖。改为 JS 手动拖拽（左键 mousedown/mousemove/mouseup + IPC），图片 pointer-events:none 统一由容器处理。右键留作换宠菜单。
2. **拖动时窗口自动放大**：Windows 高 DPI 下 Electron `getPosition()/setPosition()` 反复调用的 DIP↔物理像素舍入误差累积所致。修复：drag-start 时记录一次 bounds，drag-move 用「起始位置+总增量」算绝对位置并 `setBounds` 显式锁定 width/height。三段式 IPC：pet:drag-start / pet:drag-move / pet:drag-end。
3. **取消置顶后找不到宠物**：新增全局快捷键 Alt+P 呼出（globalShortcut，before-quit 时 unregisterAll）、托盘点击=呼出到最前（show+moveTop+focus，不改变 alwaysOnTop 设置）、托盘菜单加「呼出宠物 (Alt+P)」项。

### P1 功能实现（v1.2，15:20）
1. **帧动画**：主进程 `detectFrameSeries()` 检测同目录「前缀_序号.扩展名」序列（正则 + 按序号排序，≥2 帧才算动画），`sendPetImage()` 改为一次发帧数组 `{images, filePath, isGif, frameDelay:180}`；渲染进程逐帧抠白底后 setInterval 轮播。GIF 特判走原生动画（不抠图不轮播）。命名约定：`cat_0.png / cat_1.png ...`，选/拖任意一张即可。
2. **点击弹跳 + 悬停反应**：mouseup 用 `Math.hypot(dx,dy)` 算总位移，<6px 判定点击触发 bounce（CSS @keyframes，animationend 移除类支持连点）；悬停 `#pet-container:hover #pet-img { transform: translateY(-4px) scale(1.05) }`。
3. **演示帧**：用 Python 标准库（zlib+struct 手写 PNG）生成 `assets/frames_demo/demo_0/1/2.png` 三帧眨眼示例。
4. 验证：detectFrameSeries 检测 3 帧；src 哈希采样确认轮播（睁眼/闭眼交替）；bounce 类 + 截图差异确认弹跳生效；主程序前台启动无报错。
